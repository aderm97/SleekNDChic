1. Technology Stack

Layer	Technology	Justification

Validation	Zod	TS-first schema validation for all API inputs.
Database	PostgreSQL 15+	ACID compliance for inventory/order transactions; JSONB for flexible addresses.
Cache / Sessions	Redis (BullMQ for queues)	Guest cart TTL, session store, API caching, async notification jobs.
File Storage	AWS S3 (MinIO for dev)	Product images, carousel banners, blog assets.
Message Queue	BullMQ (Redis-backed)	Async order notifications (email/WhatsApp) without blocking checkout.

Monitoring	Prometheus + Grafana + Pino/Winston	APM metrics, centralized logging (ELK stack alternative).


2. Database Schema (PostgreSQL)

Core Tables

-- Categories for filtering
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL,
  slug VARCHAR(120) UNIQUE NOT NULL,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Products
CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(255) NOT NULL,
  description TEXT,
  base_price DECIMAL(10,2) NOT NULL,
  sku VARCHAR(100) UNIQUE NOT NULL,
  category_id UUID REFERENCES categories(id),
  low_stock_threshold INT DEFAULT 5,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Product Images (detail page carousel)
CREATE TABLE product_images (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  product_id UUID NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  url TEXT NOT NULL,
  alt_text VARCHAR(255),
  display_order INT DEFAULT 0
);

-- Variants (size/color) – Inventory tracked here
CREATE TABLE variants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  product_id UUID NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  size VARCHAR(50),
  color VARCHAR(50),
  sku_suffix VARCHAR(50), -- appended to product.sku for full SKU
  stock_quantity INT NOT NULL DEFAULT 0,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(product_id, size, color)
);

-- Composite SKU can be derived: CONCAT(p.sku, '-', v.sku_suffix)

-- State-based Shipping Configuration
CREATE TABLE state_shipping (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  state_name VARCHAR(100) NOT NULL,
  shipping_method VARCHAR(50) NOT NULL CHECK (shipping_method IN ('Authorized Car Park', 'Delivery Company')),
  price DECIMAL(10,2) NOT NULL,
  active BOOLEAN DEFAULT true,
  UNIQUE(state_name, shipping_method)
);

-- Coupons / Promotions
CREATE TABLE coupons (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code VARCHAR(50) UNIQUE NOT NULL,
  type VARCHAR(20) NOT NULL CHECK (type IN ('fixed', 'percentage')),
  value DECIMAL(10,2) NOT NULL,
  min_order_amount DECIMAL(10,2) DEFAULT 0,
  usage_limit INT,
  used_count INT DEFAULT 0,
  starts_at TIMESTAMPTZ,
  ends_at TIMESTAMPTZ,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Users (Admin/Staff only – Customers are guest-only per FR4)
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  full_name VARCHAR(255),
  role VARCHAR(20) NOT NULL CHECK (role IN ('admin', 'staff')),
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Staff Sessions (JWT refresh tracking)
CREATE TABLE staff_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token_hash VARCHAR(255) NOT NULL, -- hash of refresh token
  expires_at TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Orders
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_number VARCHAR(20) UNIQUE NOT NULL, -- human readable e.g. SC-240502-XXXX
  channel VARCHAR(20) NOT NULL DEFAULT 'website' CHECK (channel IN ('website', 'pos', 'social_media')),
  
  -- Customer info
  customer_email VARCHAR(255) NOT NULL,
  customer_phone VARCHAR(50),
  shipping_address JSONB NOT NULL, -- { state, city, street, zip, country }
  state_name VARCHAR(100), -- extracted from address for shipping lookup
  
  -- Financials
  status VARCHAR(30) DEFAULT 'pending' CHECK (status IN ('pending_payment', 'processing', 'shipped', 'delivered', 'cancelled')),
  subtotal DECIMAL(10,2) NOT NULL,
  tax DECIMAL(10,2) DEFAULT 0,
  shipping_cost DECIMAL(10,2) DEFAULT 0,
  discount_amount DECIMAL(10,2) DEFAULT 0,
  total_amount DECIMAL(10,2) NOT NULL,
  
  -- Payment
  payment_method VARCHAR(20) NOT NULL CHECK (payment_method IN ('card', 'bank_transfer')),
  payment_status VARCHAR(20) DEFAULT 'pending' CHECK (payment_status IN ('pending', 'paid', 'failed', 'refunded')),
  payment_transaction_id VARCHAR(255),
  
  -- Flags
  needs_shipping_review BOOLEAN DEFAULT false, -- when state not found in table
  coupon_id UUID REFERENCES coupons(id),
  
  -- Audit
  created_by_user_id UUID REFERENCES users(id), -- for manual/POS orders
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Order Items
CREATE TABLE order_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID NOT NULL REFERENCES orders(id) ON DELETE CASCADE,
  product_id UUID NOT NULL REFERENCES products(id),
  variant_id UUID NOT NULL REFERENCES variants(id),
  quantity INT NOT NULL CHECK (quantity > 0),
  unit_price DECIMAL(10,2) NOT NULL,
  total_price DECIMAL(10,2) NOT NULL
);

-- Inventory Adjustments (audit trail)
CREATE TABLE inventory_adjustments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  variant_id UUID NOT NULL REFERENCES variants(id),
  quantity_change INT NOT NULL, -- negative for decrement, positive for restock
  reason VARCHAR(50) NOT NULL CHECK (reason IN ('order', 'return', 'damage', 'manual', 'restock')),
  order_id UUID REFERENCES orders(id),
  adjusted_by_user_id UUID REFERENCES users(id),
  note TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Coupon Usage (accurate tracking beyond used_count)
CREATE TABLE coupon_usages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  coupon_id UUID NOT NULL REFERENCES coupons(id),
  order_id UUID NOT NULL REFERENCES orders(id),
  used_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(coupon_id, order_id)
);

-- CMS: Blog Posts
CREATE TABLE blog_posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE NOT NULL,
  content_html TEXT NOT NULL,
  excerpt TEXT,
  featured_image_url TEXT,
  published_at TIMESTAMPTZ,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- CMS: Static Pages (Shipping Policy, etc.)
CREATE TABLE pages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE NOT NULL,
  content_html TEXT NOT NULL,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- CMS: Carousel / Banners
CREATE TABLE carousel_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  image_url TEXT NOT NULL,
  target_url TEXT,
  alt_text VARCHAR(255),
  display_order INT DEFAULT 0,
  active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Notification Log (Email / WhatsApp)
CREATE TABLE notification_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id),
  recipient VARCHAR(255) NOT NULL,
  channel VARCHAR(20) NOT NULL CHECK (channel IN ('email', 'whatsapp')),
  template VARCHAR(100) NOT NULL,
  status VARCHAR(20) NOT NULL CHECK (status IN ('pending', 'sent', 'failed')),
  content TEXT,
  sent_at TIMESTAMPTZ,
  error_message TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Indexes for Performance
CREATE INDEX idx_products_active ON products(active);
CREATE INDEX idx_products_category ON products(category_id) WHERE active = true;
CREATE INDEX idx_variants_product ON variants(product_id, active);
CREATE INDEX idx_orders_status_created ON orders(status, created_at);
CREATE INDEX idx_orders_number ON orders(order_number);
CREATE INDEX idx_order_items_order ON order_items(order_id);
CREATE INDEX idx_state_shipping_name ON state_shipping(state_name, active);
CREATE INDEX idx_coupons_code ON coupons(code, active);
CREATE INDEX idx_coupon_usages_coupon ON coupon_usages(coupon_id);
CREATE INDEX idx_inventory_adj_variant ON inventory_adjustments(variant_id, created_at);


3. API Specification (Expanded)

Authentication & Security Patterns


Access Token: JWT (15-min expiry) in Authorization: Bearer <token> header for Admin.

Refresh Token: HTTP-only, SameSite=Strict, secure cookie for Admin dashboard.

Guest Sessions: UUID session_id in HTTP-only cookie; maps to Redis cart.

Rate Limiting: express-rate-limit — 100 req/min public, 20 req/min checkout, 10 req/min login.

5. Critical Architecture Decisions

Decision	Rationale
Server-side cart (Redis) over localStorage	Enables cart persistence across devices, easier manual-order merging, and avoids localStorage tampering.
Single backend service (modular monolith)	Team size ≤5 (C2); reduces ops overhead. Split into microservices only if reporting/notifications need isolated scaling.
SKU generation: PRODUCT_SKU-VARIANT_SUFFIX	Human-readable; unique constraint at DB level prevents collisions.
Bank transfer = pending_payment status	Prevents inventory blocking; admin manually confirms receipt → status moves to processing → inventory decrements.
Order number as public token	Allows guest users to track orders without passwords; sufficiently secure with UUID-based entropy.
Soft deletes via active flag	Preserves referential integrity for historical orders while allowing admin to hide products/content.
JSONB for shipping addresses	Flexibility for international expansion (FE3) without schema migrations.


6. Security & Compliance Checklist


 PCI-DSS: No raw card data touches our servers; Stripe Elements tokenizes all card inputs.

 Auth: bcrypt (cost 12); JWT access tokens short-lived; refresh tokens hashed in DB.

 Transport: TLS 1.2+ enforced; HSTS headers via NGINX/Helmet.

 Input Validation: Zod schemas on all routes; Prisma ORM prevents SQLi.

 Output Encoding: React auto-escapes XSS; CSP policy restricts inline scripts.

 CSRF: Double-submit cookie pattern for admin state-changing mutations.

 Rate Limiting: Brute-force protection on login, coupon validation, and checkout.

 RBAC: Middleware explicitly checks req.user.role against route metadata.

 File Uploads: Restrict to images (jpg/png/webp); size limit 2MB; store with random UUID filenames.

 Secrets: Managed via Kubernetes Secrets / AWS Secrets Manager; never commit .env files.



7. Scalability Path (Post-MVP)

Volume	Action
>500 orders/day	Add PostgreSQL read replica for reporting queries; separate BullMQ worker pods.
>5k orders/day	Split Order Service and Notification Service into standalone containers; introduce RabbitMQ for higher throughput.
>50k SKUs	Migrate product search to Algolia/Elasticsearch.
International	Extract shipping into microservice with carrier APIs (DHL/FedEx) per FE2.
